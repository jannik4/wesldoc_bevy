MULTISAMPLE
fn load_mip_0_single_sample(st: vec2<f32>, sample: i32) -> f32

Loads a single 2×2 square of texels at the given position from the source image, reduces them, and returns the result.

st should be in texels, not in the 0, 1 range like UVs. That is, st is uv * textureDimensions(mip_0).xy.
