bevy_render::bindless

Source

Defines the common arrays used to access bindless resources.

This need to be kept up to date with the BINDING_NUMBERS table in bindless.rs.

You access these by indexing into the bindless index table, and from there indexing into the appropriate binding array. For example, to access the base color texture of a StandardMaterial in bindless mode, write bindless_textures_2d[materials[slot].base_color_texture], where materials is the bindless index table and slot is the index into that table (which can be found in the Mesh).
