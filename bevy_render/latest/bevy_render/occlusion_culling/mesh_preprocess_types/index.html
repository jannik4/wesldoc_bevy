bevy_render::occlusion_culling::mesh_preprocess_types

Source

Types needed for GPU mesh uniform building.

Structs

  • BinMetadata

    Information about each bin in a batch set.

  • IndirectBatchSet
  • IndirectParametersIndexed

    The wgpu indirect parameters structure. This is a union of two structures. For more information, see the corresponding comment in gpu_preprocessing.rs.

  • IndirectParametersMetadata

    Information needed to construct indirect draw parameters for a single draw.

  • IndirectParametersNonIndexed
  • MeshInput

    Per-frame data that the CPU supplies to the GPU.

  • PreprocessWorkItem

    One invocation of this compute shader: i.e. one mesh instance in a view.

  • PreviousMeshInput

    Per-mesh-instance data that we retain from the previous frame.

Translate-time features

  • WRITE_INDIRECT_PARAMETERS_METADATA
