bevy_solari::scene::sampling::ResolvedLightSample

Source 
struct ResolvedLightSample {
    world_position: vec4<f32>,
    world_normal: vec3<f32>,
    radiance: vec3<f32>,
    inverse_pdf: f32,
    emission_axis: vec3<f32>,
    cone_cos_inner: f32,
    cone_cos_outer: f32,
    emission_cosine_exponent: f32,
    brdf_rays_can_hit: bool
}

A point on (or direction to) a light, resolved independently of any shading point.

Every kind of light is described by the same data, and shaded by the same formula in calculate_resolved_light_contribution.

Fields

world_position: vec4<f32>

If w = 1, the sample is a point on a light. If w = 0, it's a direction towards a light.

world_normal: vec3<f32>

The emitting surface's normal. Unused when emission_cosine_exponent is 0.

radiance: vec3<f32>
inverse_pdf: f32

inverse_pdf may not be in solid angle measure (e.g. area measure)

emission_axis: vec3<f32>

Axis of the emission cone, see emission_cone_attenuation.

cone_cos_inner: f32

Cosines of the emission cone's inner and outer angles. cos_outer <= -1 means no cone.

cone_cos_outer: f32
emission_cosine_exponent: f32

1 if emission falls off with the cosine of the angle to world_normal, e.g. emissive triangles, rect lights, and sphere lights. 0 if emission is the same in every direction, e.g. point and spot lights with no radius.

brdf_rays_can_hit: bool

Whether rays can hit this light, needed for MIS between NEE and BRDF sampling. Only emissive meshes can be hit. Analytic lights (directional, point, spot, rect) can only be found via NEE.
