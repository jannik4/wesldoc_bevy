bevy_sprite_render::mesh2d::types::Mesh2d

Source 
struct Mesh2d {
    world_from_local: mat3x4<f32>,
    local_from_world_transpose_a: mat2x4<f32>,
    local_from_world_transpose_b: f32,
    flags: u32,
    material_bind_group_slot: u32,
    tag: u32,
    metadata_index: u32
}

Fields

world_from_local: mat3x4<f32>

Affine 4x3 matrix transposed to 3x4 Use bevy_render::maths::affine3_to_square to unpack

local_from_world_transpose_a: mat2x4<f32>

3x3 matrix packed in mat2x4 and f32 as: 0.xyz, 1.x, 1.yz, 2.xy 2.z Use bevy_render::maths::mat2x4_f32_to_mat3x3_unpack to unpack

local_from_world_transpose_b: f32
flags: u32

'flags' is a bit field indicating various options. u32 is 32 bits so we have up to 32 options.

material_bind_group_slot: u32

Index of the material in the bind group data.

tag: u32
metadata_index: u32

The index of the mesh metadata buffer.
